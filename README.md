# Digital Citizenship: Level Up! 🎮

Interactive sixth-grade review website for Unit 2 (Online Safety) and Unit 3 (Communication & Collaboration).

## Features
- Topic-based study guide with 16 review areas
- Interactive flashcards
- 20-question practice quiz with instant feedback and score
- Responsive, retro arcade-inspired layout
- No logins, outside libraries, or score collection

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait for GitHub Pages to publish. The URL will look like `https://YOUR-USERNAME.github.io/digital-citizenship-level-up/`.

Quiz scores stay in the student's browser and are not sent or saved to a server.
